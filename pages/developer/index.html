Integration Guide & Code Examples

Below are templates to help you quickly integrate Phryco SSO into your application.

1. Frontend: Redirect User to Login

Attach this to your "Sign in with Phryco" button.

const clientId = "YOUR_CLIENT_ID";
const redirectUri = encodeURIComponent("https://yourwebsite.com/auth/callback");

// Redirect the user to Phryco's authorization page
window.location.href = `https://phryco.vercel.app/pages/sso/authorize.html?client_id=${clientId}&redirect_uri=${redirectUri}`;

2. Backend: Exchange Code for Access Token (Node.js Example)

Once the user is redirected back to your server with a ?code= parameter, exchange it for a token.

const formData = new URLSearchParams();
formData.append('grant_type', 'authorization_code');
formData.append('code', req.query.code); // Code from URL
formData.append('client_id', 'YOUR_CLIENT_ID');
formData.append('client_secret', 'YOUR_CLIENT_SECRET'); // Secure!
formData.append('redirect_uri', 'https://yourwebsite.com/auth/callback');

const tokenResponse = await fetch('https://api.phryco.com/api/sso/token', {
    method: 'POST',
    body: formData
});
const tokenData = await tokenResponse.json();
const accessToken = tokenData.access_token;

3. Backend: Fetch User Profile

Use the access token to securely retrieve the user's Phryco Identity.

const userResponse = await fetch('https://api.phryco.com/api/sso/userinfo', {
    headers: { 'Authorization': `Bearer ${accessToken}` }
});
const userData = await userResponse.json();

console.log(`Successfully logged in as ${userData.username}!`);
// { id: 123, username: "john_doe", avatar_path: "...", role: "USER" }
